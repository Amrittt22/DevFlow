# DevFlow

DevFlow is a collaboration platform for software teams to plan projects, track tasks and issues, and coordinate sprints.

## Project layout

- `frontend/` — React, TypeScript, Vite, and Tailwind CSS application
- `backend/` — Express API and Prisma/PostgreSQL database
- `docs/` — architecture and product documentation
- `DEVFLOW_PLAN.md` — product scope and delivery roadmap

## Start the frontend

```sh
cd frontend
npm install
npm run dev
```

The backend and database are scaffolded for later implementation.
